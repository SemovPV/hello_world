# InstaClone - Простой аналог Instagram

Простой веб-клон Instagram с базовым функционалом, без умных алгоритмов рекомендаций.

## Функционал

✅ **Регистрация и авторизация**
- Регистрация нового пользователя
- Вход в систему
- Выход из системы

✅ **Профиль пользователя**
- Просмотр своего и чужих профилей
- Редактирование профиля (имя, био, фото)
- Счётчик публикаций

✅ **Публикации (Посты)**
- Загрузка фотографий с описанием
- Лента всех постов (хронологический порядок)
- Отображение в виде сетки в профиле

✅ **Истории (Stories)**
- Публикация историй
- Автоматическое удаление через 24 часа
- Отображение в профиле с цветным ободком

## Технологии

- **Backend**: Flask (Python)
- **База данных**: SQLite
- **Frontend**: HTML, CSS, Bootstrap 5
- **Аутентификация**: Flask-Login

## Установка и запуск

### 1. Установите зависимости

```bash
cd /workspace/insta_clone
pip install -r requirements.txt
```

### 2. Запустите приложение

```bash
python app.py
```

### 3. Откройте в браузере

Перейдите по адресу: http://localhost:5000

insta_clone/

## Как пользоваться

1. **Зарегистрируйтесь** - создайте новый аккаунт
2. **Заполните профиль** - добавьте имя, био и фото
3. **Опубликуйте пост** - загрузите фото с описанием
4. **Добавьте историю** - фото исчезнет через 24 часа
5. **Просматривайте ленту** - все посты в хронологическом порядке

## Примечания

- Нет умной ленты - только хронологический порядок
- Нет лайков и комментариев (можно добавить в будущем)
- Нет подписок/фолловинга (все видят всё)
- Истории удаляются автоматически через 24 часа
